Structural statements ​

This page gives the checks of the structural statements. Every statement of this chapter has a test under test/projection/, and each test runs the case that must fail. Derivatives are computed by forward-mode automatic differentiation, so the tolerances are set by rounding error. The script scripts/projection/checks.jl runs the tests of the structural statements and prints the measured numbers of the table.

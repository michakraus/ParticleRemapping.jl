ParticleRemapping.Remapping Module
julia
Remapping

Hamiltonian remapping of weighted markers in 1D-1V: the factorisation of every symplectic redistribution into a canonical map and a gauge step, velocity rezoning by the gauge step, and canonical transport with current-quantile matching.

Velocity rezoning by the gauge step ​

ParticleRemapping.Remapping.GaugeRezoning Type
julia
GaugeRezoning(grid; K = (0, 2), s = 1, dτ0 = 0.05, dτmin = 1e-3, tol = 1e-13,
              steptol = 1e-10, maxit = 30, solver = :schur)

The velocity rezoning by the gauge step on the PeriodicGrid grid: every marker keeps its position and its momentum, its velocity is stretched by λ_a = e^{μ_a} and its weight divided by λ_a. The stretches move the speeds of each group of cell and sign towards an equispaced set (gauge_targets), subject to the conservation of the grid moments k ∈ K (0: charge, 2: kinetic energy, 3: heat flux). Newton's method (gauge_newton, with tolerance tol on the scaled constraints, steptol on the step, at most maxit iterations, and the Schur-complement or full KKT solver) follows the minimiser by a homotopy in the targets (gauge_homotopy) with the initial step dτ0 and the smallest step dτmin; the scale s only scales the multipliers.

ParticleRemapping.remap Method
julia
remap(method::GaugeRezoning, markers::Markers; targets = gauge_targets(…),
      compare_solvers = false) -> RemapResult

Run the algorithm gauge rezoning: the homotopy of gauge_homotopy, then the gauge step W_a = w_a e^{−μ_a}, V_a = p_a / (m W_a) with the last accepted μ, so that P_a = p_a holds to round-off. The info holds the log-stretches μ, the targets μstar, the multipliers α, the homotopy parameter τ reached, the smallest curvature min_curvature = min_a H_a/w_a there, the problem and the history of the homotopy.

ParticleRemapping.Remapping.GaugeRezoningProblem Type
julia
GaugeRezoningProblem(grid, markers; K = (0, 2), s = 1, targets = gauge_targets(…))

The data of the constrained problem of the gauge rezoning of 1D-1V markers on a PeriodicGrid: the two nodes and the shape-function values of each marker, the constrained moments K, the squared scale s², the targets μ* and the scales M_i^(k)[w, |v|] of the constraints. Constraint (k, i) is row (q − 1) N_g + i for the q-th entry k of K.

ParticleRemapping.Remapping.gauge_targets Function
julia
gauge_targets(grid::PeriodicGrid, x, v)

The target log-stretches μ* of the gauge rezoning. In each group of velocity_groups with n ≥ 3 markers the speeds are sorted and mapped onto the n equispaced speeds between the smallest and the largest speed of the group, keeping their order; μ*_a = ln(|V*_a| / |v_a|). Markers in smaller groups get μ*_a = 0.

ParticleRemapping.Remapping.gauge_schur_matrix Function

The Schur complement G diag(H)⁻¹ Gᵀ of the KKT matrix, of size |K| N_g: symmetric, periodic block-tridiagonal with blocks of size |K|, and positive definite when every H_a > 0 and G has full row rank.

ParticleRemapping.Remapping.gauge_newton_step Function
julia
gauge_newton_step(H, G, ∇J, c; solver = :schur) -> (Δμ, α⁺)

The Newton step of the gauge rezoning, the solution of the KKT system [diag(H) Gᵀ; G 0] [Δμ; α⁺] = −[∇J; c]. With solver = :schur the multipliers solve the Schur-complement system G diag(H)⁻¹ Gᵀ α⁺ = c − G diag(H)⁻¹ ∇J and the stretches follow marker by marker, Δμ = −diag(H)⁻¹ (∇J + Gᵀ α⁺); with solver = :kkt the full sparse KKT system is solved.

ParticleRemapping.Remapping.gauge_merit Function
julia
gauge_merit(prob::GaugeRezoningProblem, μ, τ, ν)

The ℓ¹ merit function Ψ_ν(μ) = J(μ) + ν Σ_{i,k} |c_i^(k)(μ)| / M_i^(k)[w, |v|] of the line search, with each constraint scaled by the corresponding moment of |v|.

ParticleRemapping.Remapping.gauge_newton Function
julia
gauge_newton(prob, τ, μ, α; tol = 1e-13, steptol = 1e-10, maxit = 30, solver = :schur,
             compare_solvers = false)

Newton's method on the optimality conditions of the gauge rezoning at the homotopy parameter τ (step 2 of the algorithm gauge rezoning), from the stretches μ and multipliers α. Each iteration evaluates c, G, ∇J and H; rejects if some H_a ≤ 0; solves for the Newton step (gauge_newton_step); stops when the scaled constraint residual is below tol and max |Δμ_a| < steptol; and otherwise takes the first step length t ∈ {1, 1/2, …} that does not increase the ℓ¹ merit function (gauge_merit).

Returns (; converged, μ, α, iterations), where iterations holds one (; it, residual, step, min_curvature, t, solver_difference) per iteration (step = NaN on a rejection, t = 0 on convergence). With compare_solvers = true each step is solved both ways and solver_difference is the largest difference between the Schur-complement and the full KKT solution.

ParticleRemapping.Remapping.gauge_homotopy Function
julia
gauge_homotopy(prob; dτ0 = 0.05, dτmin = 1e-3, newton...) -> (; μ, α, τ, history)

The homotopy of the algorithm gauge rezoning: from μ = 0, α = 0, τ = 0, try τ' = min(1, τ + Δτ) with gauge_newton (keywords newton...) started at the last accepted point. On success accept τ' and set Δτ ← min(2Δτ, Δτ₀); on failure halve Δτ. Stop at τ = 1 or when Δτ < Δτ_min, a fold of the solution branch.

history lists every attempt as (; τ, accepted, μ, α, iterations), starting with the point τ = 0; iterations is the record of gauge_newton.

ParticleRemapping.Remapping.SeparableMaxwellianTarget Type
julia
SeparableMaxwellianTarget(Jbar)
SeparableMaxwellianTarget(grid::PeriodicGrid, α)

The density f̂(x, v) = J(x) M(v) to be preserved by the current-quantile matching, through the cell means J̄_c of J; for J(x) = 1 + α cos x on [0, 2π) they are J̄_c = 1 + α (sin(c Δx) − sin((c − 1) Δx)) / Δx. Its cell-averaged cumulative current is F̂_c(V) = J̄_c G(V) on each branch (maxwellian_current).

ParticleRemapping.Remapping.DensityTarget Type
julia
DensityTarget(grid::PeriodicGrid, f; vmax, nx = 8, nv = 400)

The density f(x, v) to be preserved by the current-quantile matching, for any non-negative function f, periodic in x with the period grid.L. The cell-averaged cumulative currents F̂_c(sV) = (1/Δx) ∫_{C_c} ∫_0^{V} f(x, s v') v' dv' dx are tabulated on nv + 1 equidistant speeds in [0, vmax] (the trapezoidal rule in v, the midpoint rule on nx points per cell in x); f is taken to vanish for |v| > vmax. The inverse interpolates the table linearly and returns the smallest speed at which the current reaches its value.

ParticleRemapping.Remapping.branch_quantile_matching Function
julia
branch_quantile_matching(aP, total, inverse; m = 1, Δx = 1)

Steps 3–5 of the algorithm current-quantile matching on one branch of one cell, for the sorted speeds of momentum aP = |P_(1)| ≤ … ≤ |P_(n)|, the total total = F̂_c(s∞) of the cumulative current and its inverse inverse(y) = F̂_c^{−1}(y). Returns (; Π, R, Πc, V, W): the midpoint cumulative momenta Π_(r) = (Σ_{j<r} |P_(j)| + |P_(r)|/2) / (m Δx), the compatibility residual R = Σ_j |P_(j)| / (m Δx F̂_c(s∞)) − 1, the closed quantiles Πc = Π/(1 + R), the speeds |V_(r)| = F̂_c^{−1}(Πc_(r)) and the weights W_(r) = |P_(r)| / (m |V_(r)|).

ParticleRemapping.Remapping.current_quantile_match Function
julia
current_quantile_match(grid, X, P, target; m = 1) -> (V, W, R)

Steps 2–5 of the algorithm current-quantile matching: for each cell c of grid and each sign s, sort the markers with X_a ∈ C_c and sgn P_a = s by |P_a| and apply branch_quantile_matching with the cumulative current of target. Returns the new velocities V, the new weights W (with m W V = P) and the residuals R[c, 1] (s = +1) and R[c, 2] (s = −1), NaN for an empty branch.

The canonicity residual of a map (x, v) ↦ (X, V) = T(x, v) with the new weight W = Wfun(x, v, w) for a frozen weight w: |det ∂(X, P)/∂(x, v) − m w| with P = m W V, the difference from det ∂(x, p)/∂(x, v) = m w. It vanishes when the map is canonical in (x, p). The Jacobian is taken by central differences (fd_jacobian).

ParticleRemapping.Remapping.symplectic_condition_checks Function
julia
symplectic_condition_checks(; m = 1.7, samples = …)

The checks of the symplecticity condition for maps of one marker (x, v, w), each the largest residual over the sample states samples, as (; name, residual, holds) with holds the expected outcome:

  1. the gauge step (x, λ v, w/λ) with a stretch λ(x, v, w) that depends on the whole state preserves ω (pullback_residual);

  2. a canonical map of (x, p) (a kick, then a drift) followed by an arbitrary new weight W, V = P/(m W), preserves ω;

  3. control: X = x + v, which does not factor through (x, p), does not;

  4. free streaming X = x + 0.9 v does not preserve ω;

  5. free streaming is canonical in (x, p) for a frozen weight (frozen_weight_residual);

  6. X = φ(x), V = c(x) v + b(x), W = w/(φ' c) is canonical for a frozen weight;

  7. control: V = v + 0.4 v³ with W = w / det DT is not.

ParticleRemapping.remap_states Method
julia
remap_states(method::GaugeRezoning, before::Markers, result::RemapResult; steps = 2)
    -> Vector{RemapStage}

The states of the gauge rezoning of before that gave result. The canonical map is the identity, so the states are the markers before the remap, the gauge steps W = w e^{−μ} of steps accepted points of the homotopy (those closest to equispaced fractions of the parameter τ reached), and the result. Every state has the positions and the momenta of before.

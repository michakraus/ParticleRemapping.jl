Verification: Hamiltonian particle projection ​

Every statement of the Hamiltonian particle projection has a test under test/projection/, and each test runs the case that must fail. The pages Structural statements and target weights after a push and Hole filling hold the tables of the measured numbers: the structural statements, the hole-filling experiment and the target weights after a push. This section says which file checks what. Run a test file with

julia --startup-file=no --project=test test/projection/<file>.jl

and a script with

julia --startup-file=no --project=scripts scripts/projection/<file>.jl

The files of test/projection/ are in the group core of test/runtests.jl; the two files of test/projection/experiments/ are in the group slow.

The numbers of the source note ​

The numbers of the note Hamiltonian particle projection: a symplectic redistribution of weighted markers are the numbers of the first table on Structural statements and target weights after a push. The second table there, of the remaps, and the tables on Hole filling differ from the note in value: the note's fit is a damped least-squares method, and the tables give the Gauss–Newton fit with the return code of each row, and those on hole filling also the mirror-symmetric saddle that it reaches from   at   and the ranges of the seeded fits there. The two experiment scripts hold the numbers of both pages in their tables NOTE_WEIGHTS, REMAP_TABLE and NOTE, and the two experiment tests in TABLES, WEIGHT_TABLE and REMAP_TABLE; a measured number agrees with a quoted one when it lies within half a unit of the last quoted digit. A quoted range holds a number of the script between its ends, and a number of the test within the range widened on each side by its width. The experiment tests check every number of the tables in this way. Three points differ in form, not in value:

  • The note quotes the relative error of the projected target weights at   only. At   the bands and differ in the second digit ( and against and ); the hole-filling page gives both.

  • The tests assert bounds where the note quotes a measured value: below in the hole-filling test and below in the test of the target weights (the note quotes   and   relative), the mass error of the fixed rank one below , as the table quotes it (the note quotes  ), the error of the sensitivities below (the note quotes  ), and the cases that must fail above a threshold below the quoted value (for example for the charge error , for the rank-one error ). checks.jl and the experiment scripts print the measured values.

  • The cost of the maps and of the fit (seconds) is printed by hole_filling.jl and dlra_weights.jl and depends on the machine; no test checks it.

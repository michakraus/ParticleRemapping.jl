Library: Projection ​

ParticleRemapping.Projection Module
julia
Projection

Hamiltonian particle projection: remap Hamiltonians built from kicks, drifts and non-separable implicit-midpoint stages with a centroid shift, fitted to target points from a projected density; charge-conserving reweighting and target weights from a dynamical low-rank density.

The method types ​

ParticleRemapping.Projection.KickDriftRemap Type
julia
KickDriftRemap(; variant = :weight_dependent, L = 2π, V = 4, nξ = 32, nv = 40, nw = 16,
    stages = 2, projection = HatProjection(32, 33), moser_steps = 40, β = 1e-3, maxit = 40,
    density = nothing, charge = nothing, solver = :gauss_newton, seed = nothing)

The Hamiltonian particle projection with the kick–drift map of KickDriftParametrisation (variant, nξ, nv, nw, stages). The target points come from the density-interpolation flow on the hats projection with moser_steps Runge–Kutta steps, the target weights from the lumped projection f_h (density = nothing) or from density(xs, vs); the fit is fit_remap_parameters with the regularisation β, at most maxit iterations and the solver (:gauss_newton, the one solver). It starts at θ = 0 for seed = nothing, and at θ0 = 1e-3 .* randn(Xoshiro(seed), n), with n the number of parameters, for a non-negative integer seed, stored as an Int. Another solver, or a seed that is negative or above typemax(Int), throws an ArgumentError. With charge a ChargeConservingReweighting, its weights replace the target weights.

julia
remap(method, markers::Markers; targets = nothing, reference_charge = nothing)

runs the algorithm on 1D-1V markers. Precomputed targets (a NamedTuple (; x, v, w) of projection_targets) skip the first two steps. The charge-conserving reweighting keeps reference_charge, by default the grid charge of markers. The result holds the markers (x′ mod L, p′/(m w′), w′); info holds the parameters θ, the objective F0 at θ = 0 and F after the fit, objective_ratio = F/F0, the fit iterations, its status (the SolverStatus of the solver, with the return code), the lifted positions X and momenta P after the map, the targets, the parametrisation, the largest number of fixed-point iterations of a stage (stage_iterations, nothing for explicit stages), the times of the fit and of one map, the relative changes of the total momentum and of the total weight, and, with charge, the charge-conserving weights wc and the diagnostics of ChargeConservingReweighting. Target weights that are not positive throw a DomainError: the lumped projection vanishes at targets between markers when its hats are finer than the marker spacing.

ParticleRemapping.Projection.ChargeConservingReweighting Type
julia
ChargeConservingReweighting(basis::UniformBasis; tol = 1e-13, maxit = 50)
ChargeConservingReweighting(L, n; kwargs...)

The charge-conserving reweighting on the periodic cubic B-splines basis (or n splines on [0, L)): the weights after the map that minimise the relative entropy to the target weights under the constraint of the grid charge, by charge_reweight.

julia
remap(method::ChargeConservingReweighting, markers::Markers; reference_charge)

The markers carry the positions after the map, the target weights w* and the velocities p / (m w*); the result keeps the positions and the momenta and replaces the weights by w′ and the velocities by p / (m w′). info holds the multipliers λ, the Newton iterations, converged, the relative grid-charge residuals of w* and of w′ against reference_charge, and max_log_change = max_k |ln(w′_k / w*_k)|. Without a solution (a shape function with charge and no marker) it throws an ErrorException.

ParticleRemapping.Projection.mean_field_example Function
julia
mean_field_example(; τ = 0.2, center = [0.1, 0.2], radius = 0.35, n = 17, half_width = 1.2,
    jitter = 0.01, ncircle = 4000, rng = Random.default_rng())

The mean-field example of the documentation section on holes: a jittered n × n lattice of markers ζ = (ξ, η) in [−half_width, half_width]² with the disk of radius around center cut out, the moments φ(ζ) = (sin ξ η, cos ξ + 0.3 η²), the single-particle Hamiltonian h(ζ; Λ) = η²/2 + 0.4 cos ξ + Λ₁ sin(ξ + η/2) + Λ₁ Λ₂ cos ξ, which is nonlinear in the moments Λ = (1/N) Σ_k φ(z_k), and its weight-dependent control h_w(ζ, w; Λ) = h(ζ; Λ) + ½ ln w sin 2ξ η.

Returns a NamedTuple with the step τ, the functions φ, h, h_w, the markers Z0 (a vector of 2-vectors), the boundary circle of the hole (ncircle points), its center and radius.

ParticleRemapping.Projection.centroid_kick Function
julia
centroid_kick(x, p, w, gκ)

The exact time-one flow of the kick Hamiltonian H^K(x) = Σ_k κ(x_k − X_c(x), w_k), with the weighted centroid X_c = Σ_j α_j x_j, α_j = w_j / Σ_i w_i: p_k ↦ p_k − ∇_ξκ(x_k − X_c, w_k) + α_k Σ_j ∇_ξκ(x_j − X_c, w_j). The function gκ(ξ, w) returns the gradient ∇_ξ κ as a vector; x and p are d × N matrices.

ParticleRemapping.Projection.naive_kick Function
julia
naive_kick(x, p, w, gκ)

The kick p_k ↦ p_k − ∇κ(x_k, w_k) + α_k Σ_j ∇κ(x_j, w_j) with the mean force removed at unshifted positions. It conserves the total momentum but is not symplectic: the case that must fail against centroid_kick.

ParticleRemapping.Projection.velocity_drift Function
julia
velocity_drift(x, p, w, m, gη)

The exact time-one flow of the drift Hamiltonian H^D(p) = Σ_k η(p_k/(m w_k), w_k): x_k ↦ x_k + ∇_vη(p_k/(m w_k), w_k) / (m w_k). The function gη(v, w) returns ∇_v η.

ParticleRemapping.Projection.nonseparable_stage Function
julia
nonseparable_stage(x, p, w, m, gφ; tol = 1e-13, maxit = 200) -> (x′, p′, iterations, converged)

One step of the implicit midpoint rule for H(x, p) = Σ_k m w_k φ(x_k − X_c(x), p_k/(m w_k), w_k), solved in the velocity form: each marker takes an implicit-midpoint step of φ in (ξ, v), and all markers share the centroid shift c = Σ_j α_j ∇_vφ_j and the boost b = Σ_j α_j ∇_ξφ_j at the midpoints. The function gφ(ξ, v, w) returns the pair (∇_ξφ, ∇_vφ). The fixed-point iteration stops when the update, partials of dual numbers included, is below tol relative to the size of the iterate; without convergence in maxit iterations the input is returned with converged = false.

ParticleRemapping.Projection.nonseparable_hamiltonian Function

The ensemble Hamiltonian H(z) = Σ_k m w_k φ(x_k − X_c(x), p_k/(m w_k), w_k) of N markers in d dimensions as a function of the packed state z (pack). With centroid = false the positions are not shifted by the centroid: the case that must fail to conserve the momentum.

ParticleRemapping.Projection.moser_targets Function
julia
moser_targets(hp::HatProjection, s, r; steps = 40, history = nothing) -> (s*, r*)

The target points χ_1(s_k, r_k) of the density-interpolation flow, in scaled variables: the lumped marker density g_h is interpolated linearly in t to its mean ḡ = N/2, the potential solves Δφ = g_h − ḡ (periodic in s, Neumann in r, by the pseudo-inverse of moser_laplacian), and the points follow u_t = ∇φ / ((1 − t) g_h + t ḡ) with steps steps of the classical Runge–Kutta method. A vector history receives the points after each step.

ParticleRemapping.Projection.projection_targets Function
julia

The target points and target weights of the markers (x_k, v_k, w_k) on [0, L) × [−V, V]: the lifted target positions and the target velocities of moser_targets, and the target weights w*_k = c f(x*_k, v*_k) with c = Σ_j w_j / Σ_j f(x*_j, v*_j), so that the total weight is exact. With density = nothing, f is the lumped projection f_h of the represented density; otherwise density(xs, vs) returns the values of f at the vectors of target points.

ParticleRemapping.Projection.AbstractRemapParametrisation Type
julia
AbstractRemapParametrisation

A family of symplectic maps R_θ of 1D-1V markers with a parameter vector θ: KickDriftParametrisation and NonSeparableParametrisation. Each implements remap_stages and remap_parameter_count.

ParticleRemapping.Projection.KickDriftParametrisation Type
julia
KickDriftParametrisation(w; variant = :weight_dependent, L = 2π, V = 4, nξ = 32, nv = 40,
    nw = 16, stages = 2)

The kick–drift map R_θ = D_S ∘ K_S ∘ … ∘ D_1 ∘ K_1 of stages stages for markers with the weights w, with nξ periodic cubic splines B_i on [0, L), nv cubic splines B̂_j on [−V, V] and nw cubic splines C_l on [min ln w, max ln w] (for equal weights on [ln w, ln w + 1]). The variant selects the generating functions:

  • :weight_dependent: κ = w Σ λ_il B_i(ξ) C_l(ln w), η = w Σ μ_jl B̂_j(v) C_l(ln w);

  • :control_A: κ = w̄ Σ λ_i B_i(ξ), η = w̄ Σ μ_j B̂_j(p/(m w̄)) with the mean weight w̄, no dependence on the weight in (x, p);

  • :control_B: κ = w Σ λ_i B_i(ξ), η = w Σ μ_j B̂_j(v), one area-preserving map of (x, v).

The parameters of stage s are (vec(λ^s), vec(μ^s)), stage after stage.

ParticleRemapping.Projection.NonSeparableParametrisation Type
julia
NonSeparableParametrisation(w; L = 2π, V = 4, nξ = 16, nv = 17, nℓ = 6, stages = 2,
    weighted = true, iteration_limit = 50)

The map of stages non-separable implicit-midpoint stages for markers with the weights w, with φ_s(ξ, v, ℓ) = Σ λ^s_ijl B_i(ξ) B̂_j(v) C_l(ℓ) / m, ℓ = ln w, so that ψ_s = m w φ_s; nξ periodic cubic splines on [0, L), nv on [−V, V] and nℓ on [min ln w, max ln w] (for equal weights on [ln w, ln w + 1]). With weighted = false (control C) every marker evaluates φ_s at the mean of ln w, which makes the map one area-preserving map of (x, v). A stage whose fixed-point iteration needs more than iteration_limit iterations makes the map return NaN positions, so that a fit rejects such parameters: the limit keeps the contraction rate of the iteration below about 0.55. The parameters of stage s are vec(λ^s) with the linear index of (i, j, l).

ParticleRemapping.Projection.nonseparable_map Function
julia
nonseparable_map(par::NonSeparableParametrisation, θ, x, p, w; m = 1,
    sensitivities = false, centroid_terms = true, maxit = par.iteration_limit,
    history = nothing) -> (; X, P, iterations, sens)

The image of the markers with lifted positions x, momenta p and weights w (vectors) under the stages of par, each solved by nonseparable_stage with at most maxit iterations; iterations is the largest number that a stage needed. Without convergence X and P are NaN.

With sensitivities = true, sens = (; dξ, dv, dXc) holds the derivatives of the shifted positions ξ_k, of the velocities v_k and of the centroid X_c with respect to θ (dξ, dv are length(θ) × N), from the linearised step equations: one 2 × 2 system per marker and one 2 × 2 system for the shift c and the boost b. With centroid_terms = false the terms of c and b are dropped, the case that must fail. A vector history receives (X, P) after each stage.

ParticleRemapping.Projection.fit_remap_parameters Function
julia
fit_remap_parameters(par, x, p, w, xt, vt, wt; m = 1, ℓx, ℓv, β = 1e-3, maxit = 40,
    trace = false, solver = :gauss_newton, θ0 = nothing)
    -> (; θ, F0, F, iterations, status)

The parameters θ of the map par that minimise

julia
J(θ) = ½ Σ_k (|x^S_k − x*_k|² / ℓx² + |p^S_k/(m w*_k) − v*_k|² / ℓv²) + (β/2) |θ|²,

with (x^S, p^S) = R_θ(x, p) (remap_stages) and the targets (xt, vt, wt), from the start θ0 (θ = 0 for nothing; a finite vector of remap_parameter_count entries, converted to Float64), with at most maxit ≥ 0 iterations, an integer.

The solver, solver = :gauss_newton, is GeometricSolvers' GaussNewton(; globalization = DogLeg()) on the least-squares problem of the residual [r; √β θ] with the Jacobian [∂r/∂θ; √β I], with max_iterations = maxit and GeometricSolvers' default tolerances; status is its SolverStatus, whose code says why the solve ended (SUCCESS on a convergence test, with stationary set for the stationarity test; MAXITERS after the budget). A trial θ with a non-finite residual is left to the step rule of the solver. With trace = true it prints the return code, the iterations and F/F0 after the solve.

Returns the parameters, the objective F0 at θ = 0 (whatever the start) and F at the returned θ, the number of iterations and the status. A solver other than :gauss_newton, a negative maxit, a maxit above typemax(Int32) or a β that is negative, infinite or NaN throws an ArgumentError, a non-integer maxit a TypeError, a θ0 of the wrong length a DimensionMismatch, and a non-finite θ0 an ArgumentError.

ParticleRemapping.Projection.charge_reweight Function
julia
charge_reweight(b::UniformBasis, x, wstar, ρ; tol = 1e-13, maxit = 50)
    -> (; w, λ, iterations, converged)

The weights w_k = w*_k exp(Σ_i λ_i Λ_i(x_k)) with the grid charge A w = ρ (spline_charge_matrix). The multipliers λ minimise the convex dual Φ(λ) = Σ_k w_k(λ) − λᵀρ; Newton's method with a backtracking (Armijo) line search on Φ solves for them. The line search evaluates the change Σ_k w_k (e^{s (Aᵀδ)_k} − 1) − s δᵀρ of Φ along the step sδ directly, so that its rounding error stays below the decrease of a Newton step near the solution. The iteration stops when |A w − ρ| < tol max(ρ), and reports converged = false when the Hessian A diag(w) Aᵀ is not positive definite (a shape function without markers) or the iteration does not converge in maxit iterations.

The least-norm additive correction w = w* + Aᵀ(AAᵀ)⁻¹(ρ − A w*). It reproduces the grid charge ρ but can give negative weights where small target weights meet an excess of charge: the case that must fail against charge_reweight.

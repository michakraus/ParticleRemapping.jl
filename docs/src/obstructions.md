# [What a symplectic redistribution can do](@id obstructions)

```@meta
CurrentModule = ParticleRemapping
```

The [factorisation lemma](@ref factorisation-lemma) characterises the symplectic redistributions:
a canonical map ``\psi`` of ``(x, p)`` and a free choice of the weights. This chapter asks what
such a map can achieve. Five facts decide it, and each construction of the manual is shaped by
them:

1. for a finite marker set, symplecticity alone restricts almost nothing; the content is that
   one smooth map, with few parameters, moves all markers
   ([finite marker sets](@ref finite-marker-sets));
2. a canonical map that is the same for every marker moves a hole but keeps its volume
   ([Liouville](@ref liouville-holes)); this includes every map generated by a Hamiltonian that
   does not depend on the weights ([one map for all markers](@ref one-map-for-all-markers));
3. a Hamiltonian that depends on the weights compresses the marker density at a rate given by a
   Poisson bracket with the weight field
   ([weight-dependent Hamiltonians](@ref weight-dependent-hamiltonians));
4. a weight tied to a density at the new velocity folds the velocity–momentum relation, so the
   new state is computed from ``(\bar{x}, \bar{v})``, never from ``\bar{p}``
   ([the fold](@ref velocity-momentum-fold));
5. parameters computed from the markers make the map symplectic only for their frozen values,
   unless they satisfy a variational closure
   ([state-dependent parameters](@ref state-dependent-parameters)).

## [Finite marker sets](@id finite-marker-sets)

For a finite marker set, symplecticity alone imposes nothing on the final positions. The
translations ``x_a \mapsto x_a + c_a``, ``p_a \mapsto p_a + b_a`` with constants ``c_a``,
``b_a`` and ``\sum_a b_a = 0`` are canonical, conserve ``P``, and map any configuration to any
other, so any target configuration is the image of a canonical map whose parameters are computed
from the data. The condition has content in two cases. Either the map is exactly symplectic as a
function of the full state, as the gauge step and the [elementary maps](@ref elementary-canonical-maps)
are. Or one smooth map with few parameters, in the variables ``(x, p, w)``, moves all markers, as
the physical evolution does. The rest of this chapter works out the consequences of the second
case.

## [Liouville's theorem for the marker density](@id liouville-holes)

Let the markers have a smooth density ``g(x, v) > 0``, the number of markers per unit volume,
and a smooth weight field ``w(x, v) > 0``, so that the represented density is ``f = g \, w``: the
weight in a small region is ``g \, w \, \mathrm{d}x \, \mathrm{d}v``. The *sheet map*
``\sigma(x, v) = (x, m \, w(x, v) \, v)`` carries the markers to canonical coordinates, where they
have a density ``n(x, p)`` (see [the fold](@ref velocity-momentum-fold) for ``n`` in terms of
``g`` and ``w``).

Let ``\psi`` be a canonical map of the single-marker space ``\mathcal{M}``, the same for all
markers. It carries the markers in a region ``D`` to ``\psi(D)`` and preserves the volume,
``|\psi(D)| = |D|``, so the marker count ``\iint_D n = \iint_{\psi(D)} \tilde{n}`` for every ``D``
gives the transported canonical density

```math
\tilde{n} = n \circ \psi^{-1} .
```

This is Liouville's theorem for the marker density. Its consequence for a hole — a region in
which ``n`` is small — is that ``\psi`` moves the hole but keeps its volume: the level sets
``\{ \tilde{n} > c \} = \psi(\{ n > c \})`` have the volumes of the level sets of ``n``, for every
``c``. A smooth canonical map applied to every marker therefore rearranges the canonical marker
density; it cannot fill a hole. It can only move it, for example into the tails of ``f``, where
few markers are needed. The canonical transport of the first construction states the condition
precisely ([the limit of equidistribution](@ref remap-limit)).

### [One map for all markers](@id one-map-for-all-markers)

The ensemble maps that the constructions use are not, at first sight, single-marker maps: they
are flows or integrator steps of a Hamiltonian ``H`` on ``\mathcal{Z}``. Many of them still act as
one map of ``\mathcal{M}``. Let ``\mu_N = \sum_a \delta_{z_a}`` be the empirical measure of the
markers on ``\mathcal{M}``.

!!! info "Definition (mean-field Hamiltonian)"
    A Hamiltonian ``H : \mathcal{Z} \to \mathbb{R}`` is a *mean-field Hamiltonian* if there is,
    for each measure ``\mu`` in a neighbourhood of the empirical measures, a smooth function
    ``\Psi_\mu : \mathcal{M} \to \mathbb{R}`` with

    ```math
    \nabla_{z_a} H(z) = \nabla \Psi_{\mu_N}(z_a) \qquad \text{for all } a .
    ```

Examples are ``H = \sum_a h(z_a)`` with ``\Psi = h``; a sum ``H = \sum_a h(z_a; \Lambda(\mu_N))``
whose parameters ``\Lambda`` are moments ``\int \varphi \, \mathrm{d}\mu_N`` of the empirical
measure; and pair potentials ``H = \tfrac{1}{2} \sum_{a,b} u(z_a - z_b)`` with ``u`` even, for
which ``\Psi_\mu = \int u(\cdot - \zeta) \, \mathrm{d}\mu(\zeta)``. A smooth function
``H = F(\mu_N)`` of the empirical measure is a mean-field Hamiltonian with
``\Psi_\mu = \delta F / \delta \mu``. In particular, a Hamiltonian that is parametrised on a
B-spline basis and whose parameters are computed from the markers is a mean-field Hamiltonian, if
the parameters are held fixed or if their dependence on the markers is kept inside ``H``.

!!! info "Proposition (one map for all markers)"
    Let ``H`` be a mean-field Hamiltonian, and let ``\bar{z} = R(z)`` be its exact time-``\tau``
    flow or one step of symplectic Euler or of the implicit midpoint rule with step ``\tau``, such
    that the step equations have a unique solution. Then there is one symplectic diffeomorphism
    ``\psi : \mathcal{M} \to \mathcal{M}`` with ``\bar{z}_a = \psi(z_a)`` for all ``a``.

!!! details "Proof"
    *Exact flow.* By the definition, every marker solves
    ``\dot{z}_a = \mathbb{J} \nabla \Psi_t(z_a)`` with the same time-dependent Hamiltonian
    ``\Psi_t = \Psi_{\mu_N(t)}`` on ``\mathcal{M}``. Let ``\psi`` be the time-``\tau`` flow of
    this non-autonomous Hamiltonian vector field. It is a symplectic diffeomorphism of
    ``\mathcal{M}``, and ``z_a(\tau) = \psi(z_a(0))``.

    *Symplectic Euler.* The step reads
    ``\bar{p}_a = p_a - \tau \nabla_{x_a} H(x, \bar{p})``,
    ``\bar{x}_a = x_a + \tau \nabla_{p_a} H(x, \bar{p})``. Let
    ``\hat{\mu} = \sum_a \delta_{(x_a, \bar{p}_a)}`` be the empirical measure of the solution at
    the mixed arguments. By the definition, each marker satisfies

    ```math
    \bar{p}_a = p_a - \tau \nabla_\xi \Psi_{\hat\mu}(x_a, \bar{p}_a), \qquad
    \bar{x}_a = x_a + \tau \nabla_\eta \Psi_{\hat\mu}(x_a, \bar{p}_a),
    ```

    which is the symplectic Euler step of the autonomous single-marker Hamiltonian
    ``\Psi_{\hat\mu}`` on ``\mathcal{M}``. With ``\hat{\mu}`` fixed, this step defines one
    symplectic map ``\psi`` of ``\mathcal{M}``, and ``\psi(z_a) = \bar{z}_a`` for every ``a``. The
    implicit midpoint rule is identical, with ``\hat{\mu}`` the empirical measure of the
    midpoints ``(z_a + \bar{z}_a)/2``.

### [Holes persist](@id holes-persist)

!!! info "Corollary (holes persist)"
    Under the assumptions of the proposition, let ``U \subset \mathcal{M}`` be an open set that
    contains no marker ``z_a``. Then ``\psi(U)`` contains no marker ``\bar{z}_a``, and
    ``\operatorname{vol} \psi(U) = \operatorname{vol} U``. If the markers sample a density ``G``
    on ``\mathcal{M}``, the new markers sample ``G \circ \psi^{-1}``, and the volume
    ``|\{ G > s \}|`` of every superlevel set is invariant.

!!! details "Proof"
    If ``\bar{z}_a \in \psi(U)``, then ``z_a = \psi^{-1}(\bar{z}_a) \in U``, a contradiction. A
    symplectic map preserves the Liouville volume. The density statement is the transformation
    rule of a density under a volume-preserving map.

A mean-field Hamiltonian therefore only rearranges the marker density in ``(x, p)``. It cannot
fill a hole, and it cannot change the distribution of the density values. This holds
independently of how the parameters were chosen. The corollary keeps the volume of a hole, not
its shape: an area-preserving map can stretch a hole into a thin band, which reduces the largest
empty disk while the empty volume stays the same. To carry the statement over to ``(x, v)``,
consider the chart ``\chi(x, p) = (x, p / (m W(x, p)))``, where ``W`` is a smooth field of
weights. Where ``\chi`` is a diffeomorphism onto its image, it maps holes to holes. A
[gauge step](@ref gauge-step) with a smooth weight field therefore leaves a hole open in
``(x, v)`` too.

The example of
[`mean_field_example`](@ref ParticleRemapping.Projection.mean_field_example) has 274 markers on a
jittered lattice with a disk cut out, the moments
``\varphi(\zeta) = (\sin\xi\,\eta, \cos\xi + 0.3\eta^2)`` and the single-marker Hamiltonian
``h(\zeta; \Lambda) = \eta^2/2 + 0.4 \cos\xi + \Lambda_1 \sin(\xi + \eta/2) + \Lambda_1 \Lambda_2
\cos\xi``, nonlinear in the moments. Its single-marker Hamiltonian is
``\Psi_\mu(\zeta) = h(\zeta; \Lambda) + \tfrac{1}{N} \sum_b \partial_\Lambda h(z_b; \Lambda)
\cdot \varphi(\zeta)``
([`mean_field_single_hamiltonian`](@ref ParticleRemapping.Projection.mean_field_single_hamiltonian)).
One step of symplectic Euler or of the implicit midpoint rule with ``\tau = 0.2`` on the whole
ensemble agrees with the single-marker map ``\psi`` to ``6.8 \cdot 10^{-16}`` while the markers
move up to ``0.39``; ``|\det D\psi - 1| \le 2.2 \cdot 10^{-16}``; the area ``0.384845`` of the
hole is unchanged, and no marker lies in its image. The control, a weight-dependent Hamiltonian
``h_w = h + \tfrac12 \ln w \sin 2\xi\, \eta`` with two coincident markers of the weights ``0.5``
and ``2``, maps them to points ``0.14`` apart, so no single map exists
(`test/projection/structure.jl`).

```@example obstructions

Random.seed!(20261119)
plot_mean_field_step(mean_field_step_example(mean_field_example()))
```

The markers and the hole (shaded) before and after one implicit-midpoint step: the image of the
hole contains no marker.

### [Uncoupled maps](@id uncoupled-maps)

The simplest single-marker map is the one that does not couple the markers at all.

!!! info "Proposition (obstruction for uncoupled maps)"
    Let ``\psi`` be a symplectic diffeomorphism of ``\mathcal{M} = \mathbb{R}^{2d}`` and let
    ``(\bar{x}_a, \bar{p}_a) = \psi(x_a, p_a)`` for every marker. If an open set
    ``U \subset \mathcal{M}`` holds no marker ``(x_a, p_a)``, then ``\psi(U)`` holds no marker
    ``(\bar{x}_a, \bar{p}_a)``, and ``|\psi(U)| = |U|``. With equal output weights
    ``\bar{w}_a = c`` the hole of the markers in ``(x, v)`` keeps its volume
    ``|U| / (m c)^d``.

!!! details "Proof"
    The first part is the corollary [holes persist](@ref holes-persist) for
    ``H = \sum_a h(z_a)``. With ``\bar{w}_a = c``,
    ``(\bar{x}, \bar{v}) = (\bar{x}, \bar{p} / (m c))``, a linear map of determinant
    ``(m c)^{-d}``.

A canonical map of all ``N`` markers keeps the volume of ``\mathcal{Z}``, not that of
``\mathcal{M}``, so a map that couples the markers — other than through a mean field — is free of
this obstruction. The constructions leave it in two ways. A Hamiltonian that depends on the
weights moves markers of different weights with different maps (the next section; the
[Hamiltonian particle projection](@ref projection-index)). A Hamiltonian or a map that couples
the markers through their order or their pairs breaks the single-marker form (the
[pairwise Hamiltonians](@ref rd-symmetric-hamiltonians) of the spline-projection redistribution,
which also explain why uncoupled control Hamiltonians and the subtraction of a mean force fail,
and the slices of the [sliced redistribution](@ref sliced-overview)).

## [Weight-dependent Hamiltonians](@id weight-dependent-hamiltonians)

Let ``\nu_N = \sum_a \delta_{(z_a, w_a)}`` be the empirical measure on
``\mathcal{M} \times \mathbb{R}_{>0}``, and let

```math
\nabla_{z_a} H(z; w) = \nabla_\zeta \Psi(z_a, w_a)
```

with one function ``\Psi(\zeta, w)``, which may depend on ``\nu_N``. Markers with different
weights then move under different symplectic maps, and they can move through each other. The
equation of motion of a marker is ``\dot{z}_a = \mathbb{J} \nabla_\zeta \Psi(z_a, w_a)``, and its
weight is constant.

In the continuum limit, let the markers sample a density ``G`` on ``\mathcal{M}``, and let their
weights be the values of a smooth field, ``w_a = W(z_a)``. Write
``\{A, B\} = \sum_{i} ( \partial_{\xi^i} A \, \partial_{\eta_i} B - \partial_{\eta_i} A \, \partial_{\xi^i} B )``
for the canonical Poisson bracket on ``\mathcal{M}``
([`canonical_bracket`](@ref ParticleRemapping.Projection.canonical_bracket)).

!!! info "Proposition (compressibility)"
    The markers move on ``\mathcal{M}`` with the effective velocity field

    ```math
    u(\zeta) = \mathbb{J} \nabla_\zeta \Psi(\zeta, W(\zeta)) .
    ```

    Its divergence is

    ```math
    \operatorname{div} u = \{W, \partial_w \Psi\} ,
    ```

    evaluated at ``w = W(\zeta)``. Along the path of a marker, the marker density changes as

    ```math
    \frac{\mathrm{d}}{\mathrm{d}t} \ln G = - \{W, \partial_w \Psi\} ,
    ```

    and the weight field is transported, ``\partial_t W + u \cdot \nabla W = 0``.

!!! details "Proof"
    With ``u = (\nabla_\eta \Psi, -\nabla_\xi \Psi)`` evaluated at ``w = W(\xi, \eta)``, the
    chain rule gives

    ```math
    \begin{aligned}
    \operatorname{div} u
    &= \sum_i \partial_{\xi^i} \big[ \partial_{\eta_i} \Psi(\xi, \eta, W) \big]
     - \partial_{\eta_i} \big[ \partial_{\xi^i} \Psi(\xi, \eta, W) \big] \\
    &= \sum_i \big( \partial_{\xi^i}\partial_{\eta_i} \Psi + \partial_w \partial_{\eta_i} \Psi \, \partial_{\xi^i} W
     - \partial_{\eta_i}\partial_{\xi^i} \Psi - \partial_w \partial_{\xi^i} \Psi \, \partial_{\eta_i} W \big) \\
    &= \sum_i \big( \partial_{\xi^i} W \, \partial_{\eta_i} (\partial_w \Psi)
     - \partial_{\eta_i} W \, \partial_{\xi^i} (\partial_w \Psi) \big)
     = \{W, \partial_w \Psi\} .
    \end{aligned}
    ```

    The continuity equation ``\partial_t G + \operatorname{div} (G u) = 0`` gives the rate of
    ``\ln G``. The weights are constant along the marker paths, which is the transport equation
    for ``W``.

The proposition holds as long as ``W`` stays single-valued. Where markers of different weights
reach the same point, the density is a sum over sheets, and the formula holds on each sheet.

!!! info "Corollary (equal weights)"
    Where all markers carry the same weight, ``\nabla W = 0`` and the effective field is
    divergence-free. If all weights are equal, every Hamiltonian of the weight-dependent form acts
    as a mean-field Hamiltonian, and the corollary [holes persist](@ref holes-persist) applies.

The marker density can thus change only where the old weights vary, and the rate is controlled
by ``\partial_w \Psi``. After an equidistributed loading, the weights are proportional to ``f``,
so ``W`` varies wherever ``f`` varies. With equal weights, that is with markers loaded
proportional to ``f``, no map of this class changes the marker density. The
[Hamiltonian particle projection](@ref projection-index) is built on this proposition.

For random smooth ``\Psi(\xi, \eta, w)`` and ``W(\xi, \eta)`` in ``d = 1, 2, 3``,
[`effective_divergence`](@ref ParticleRemapping.Projection.effective_divergence) and
[`compressibility_bracket`](@ref ParticleRemapping.Projection.compressibility_bracket) agree to
``1.1 \cdot 10^{-15}`` at random points; the bracket with the opposite sign misses by at least
``7.8 \cdot 10^{-2}``, and the divergence at frozen weight
([`frozen_weight_divergence`](@ref ParticleRemapping.Projection.frozen_weight_divergence)) by at
least ``3.9 \cdot 10^{-2}`` (`test/projection/structure.jl`).

## [The velocity–momentum fold](@id velocity-momentum-fold)

A redistribution that ties the new weight to a density at the new velocity meets a fold. Fix a
position ``\bar{x}``, a volume ``\Delta\Omega > 0`` and a density ``f_h(\bar{x}, \cdot) > 0``,
and let the weight of a marker at ``(\bar{x}, \bar{v})`` be
``\bar{w} = \Delta\Omega \, f_h(\bar{x}, \bar{v})``. Its momentum is then a function of its
velocity,

```math
P_{\bar{x}}(\bar{v}) = m \, \Delta\Omega \, \bar{v} \, f_h(\bar{x}, \bar{v}) .
```

The same relation appears in three places: as the *sheet map*
``\sigma(x, v) = (x, m \, w(x, v) \, v)`` of a smooth weight field (with
``\Delta\Omega \, f_h = w``); as the *implicit weight* ``\bar{w} = c f_h(\bar{x}, \bar{p} / (m \bar{w}))``
that requirement (R3) suggests at fixed ``(\bar{x}, \bar{p})`` (with ``\Delta\Omega = c``); and as
the weight of a target point ``(\bar{x}, \bar{v})`` in the spline-projection redistribution.

!!! info "Proposition (velocity–momentum fold)"
    Let ``f_h(\bar{x}, \cdot)`` be ``C^1`` and positive on ``\mathbb{R}^d`` with
    ``|\bar{v}| f_h(\bar{x}, \bar{v}) \to 0`` as ``|\bar{v}| \to \infty``. Then:

    1. The Jacobian of ``P_{\bar{x}}`` is ``D_{\bar{v}} P_{\bar{x}} = m \Delta\Omega
       \big( f_h I + \bar{v} \otimes \nabla_{\bar{v}} f_h \big)``, with determinant
       ```math
       \det D_{\bar{v}} P_{\bar{x}} = (m \Delta\Omega)^d \, f_h^{\,d-1}
       \big( f_h + \bar{v} \cdot \nabla_{\bar{v}} f_h \big) .
       ```
    2. The image is bounded: ``|P_{\bar{x}}(\bar{v})| \le p_{\max}(\bar{x}) :=
       \max_{\bar{v}} m \Delta\Omega \, |\bar{v}| f_h(\bar{x}, \bar{v}) < \infty``.
    3. For a Maxwellian ``f_h(\bar{x}, \bar{v}) = C(\bar{x})
       \exp(-|\bar{v}|^2 / (2 v_{\mathrm{th}}^2))``, the determinant vanishes on the thermal
       sphere ``|\bar{v}| = v_{\mathrm{th}}`` and is negative for ``|\bar{v}| > v_{\mathrm{th}}``.
       On each ray through the origin, ``|P_{\bar{x}}|`` increases from zero to
       ``p_{\max} = m \Delta\Omega \, v_{\mathrm{th}} C e^{-1/2}`` and decreases to zero, so
       ``P_{\bar{x}}(\bar{v}) = \bar{p}`` has two solutions for ``0 < |\bar{p}| < p_{\max}`` and
       none for ``|\bar{p}| > p_{\max}``.

!!! details "Proof"
    Differentiating ``\bar{v}_i f_h`` with respect to ``\bar{v}_j`` gives
    ``f_h \delta_{ij} + \bar{v}_i \partial_{\bar{v}_j} f_h``. Factoring out ``f_h I`` and applying
    the matrix determinant lemma ``\det(I + u \otimes w) = 1 + u \cdot w`` gives the determinant.
    The bound follows from continuity and ``|\bar{v}| f_h \to 0``. For the Maxwellian,
    ``f_h + \bar{v} \cdot \nabla_{\bar{v}} f_h = (1 - |\bar{v}|^2 / v_{\mathrm{th}}^2) f_h``, and
    ``r \mapsto r \exp(-r^2 / 2 v_{\mathrm{th}}^2)`` has its only maximum on ``r > 0`` at
    ``r = v_{\mathrm{th}}``.

**The sheet.** For a smooth weight field the sheet map has, at fixed ``x``, the derivative
``\partial_v p = m \, \partial_v (w v)`` in one dimension. Under the *single-sheet condition*
``\partial_v (w v) > 0`` it is a diffeomorphism onto its image that preserves the sign of ``v``,
and counting the markers in a region ``D`` in two ways,
``\iint_D g \, \mathrm{d}x \, \mathrm{d}v = \iint_{\sigma(D)} n \, \mathrm{d}x \, \mathrm{d}p``,
gives the canonical marker density

```math
n = \frac{g}{m \, \partial_v (w v)} \circ \sigma^{-1} .
```

The single-sheet condition holds for equal weights, the case of markers loaded with density
``g \propto f``. It fails for uniformly loaded markers with ``w \propto f`` and a Maxwellian
``f``: the sheet folds at ``|v| = v_{\mathrm{th}}``. A folded sheet consists of several layers in
``(x, p)``, each of which is transported separately; the canonical transport treats one layer.
Markers equidistributed in ``(x, v)`` with weights ``c f_h`` have a density in ``(x, p)`` that is
singular on the image of the fold.

**The consequence for every construction.** A canonical momentum above ``p_{\max}(\bar{x})`` has
no velocity, and every momentum below it has at least a subthermal and a suprathermal one. A
construction therefore never computes ``(\bar{x}, \bar{p})`` first and then solves for
``\bar{v}``. It specifies ``(\bar{x}, \bar{v})`` — a target point — and evaluates the weight
``\bar{w}`` and the momentum ``\bar{p} = m \bar{w} \bar{v}`` forward, uniquely and smoothly across
all velocities, the suprathermal tail included. The Hamiltonian particle projection takes the new
weight from a target point; the spline-projection redistribution weighs its relaxed targets.

[`velocity_fold_momentum`](@ref ParticleRemapping.Redistribution.velocity_fold_momentum)
evaluates ``P_{\bar{x}}``,
[`velocity_fold_determinant`](@ref ParticleRemapping.Redistribution.velocity_fold_determinant) the
determinant with ``\nabla_{\bar{v}} f_h`` by automatic differentiation, and
[`maxwellian_fold_momentum_bound`](@ref ParticleRemapping.Redistribution.maxwellian_fold_momentum_bound)
the bound ``p_{\max}``. The test `test/redistribution/canonical.jl` checks the determinant against
the Jacobian of ``P_{\bar{x}}`` for an anisotropic density in two dimensions;
`test/projection/structure.jl` checks it in ``d = 1, 2, 3`` to a relative ``1.7 \cdot 10^{-15}``
(with ``f^d`` in place of ``f^{d-1}`` it misses by at least ``2.4 \cdot 10^{-3}`` for
``d \ge 2``), and that the Maxwellian has two roots at ``p_{\max}/2`` and none at
``3 p_{\max}/2``
([`maxwellian_fold_roots`](@ref ParticleRemapping.Projection.maxwellian_fold_roots)).

```@example obstructions

f(v) = isotropic_maxwellian(v; vth = vth)
vs = collect(range(-4.5, 4.5; length = 601))
plot_velocity_momentum_fold(vs, velocity_fold_momentum.(f, vs; m = m, ΔΩ = ΔΩ),
    velocity_fold_determinant.(f, vs; m = m, ΔΩ = ΔΩ); vth = vth,
    pmax = maxwellian_fold_momentum_bound(; vth = vth, m = m, ΔΩ = ΔΩ))
```

The figure shows, for ``v_{\mathrm{th}} = 1.3``, ``m = 1.5`` and ``\Delta\Omega = 0.2``,
(left) the momentum ``P(\bar{v})`` of a marker whose weight is tied to the Maxwellian, bounded by
``\pm p_{\max}`` (dotted) and turning back on the thermal sphere (dashed), and (right) the
determinant ``m \Delta\Omega (f_h + \bar{v} \partial_{\bar{v}} f_h)``, which vanishes there and is
negative on the suprathermal velocities (shaded). The momentum of ``0.5 v_{\mathrm{th}}`` has a
second, suprathermal velocity, which bisection on ``(v_{\mathrm{th}}, 10 v_{\mathrm{th}})`` finds:

```@example obstructions

        mid = (lo + hi) / 2
        P(mid) > target ? (lo = mid) : (hi = mid)
    end

end

```

## [Parameters that depend on the state](@id state-dependent-parameters)

Every construction of the manual computes something from the markers: stretches, parameters of a
Hamiltonian, slices, multipliers. This section states what that does to symplecticity.

### [Two readings of symplecticity](@id two-readings)

The factorisation lemma answers the question for the form ``\omega_N``, in which the weights are
coordinates. The dynamics does not preserve this form. For free streaming,
``\Phi_t(x, v, w) = (x + v t, v, w)``, one 1D-1V marker gives
``\mathrm{d}\bar{x} = \mathrm{d}x + t \, \mathrm{d}v`` and
``\mathrm{d}\bar{p} = m (w \, \mathrm{d}v + v \, \mathrm{d}w)``, so that

```math
\Phi_t^* \omega_N - \omega_N
= m ( \mathrm{d}x + t \, \mathrm{d}v ) \wedge ( w \, \mathrm{d}v + v \, \mathrm{d}w )
- m \, \mathrm{d}x \wedge ( w \, \mathrm{d}v + v \, \mathrm{d}w )
= m \, t \, v \, \mathrm{d}v \wedge \mathrm{d}w \neq 0 .
```

The pull-back residual of free streaming over ``t = 0.9`` is ``m t |v|``, the entry of
``\mathrm{d}v \wedge \mathrm{d}w``:

```@example obstructions
stream(z) = [z[1] + 0.9z[2], z[2], z[3]]
(pullback_residual(stream, [0.3, -1.2, 0.8]; m = 1.7), 1.7 * 0.9 * 1.2)
```

The flow of the Hamiltonian ``H(x, p; w)`` preserves ``\omega`` only for fixed weights. In the
coordinates ``(x, p, w)`` it is a Poisson map of the bracket

```math
\{F, G\} = \sum_a \big( \nabla_{x_a} F \cdot \nabla_{p_a} G - \nabla_{p_a} F \cdot \nabla_{x_a} G \big) ,
```

for which every ``w_a`` is a Casimir. A Poisson map sends Casimirs to functions of Casimirs, so in
this reading a redistribution may change the weights only as ``\bar{w}_a = F_a(w_1, \dots, w_N)``.

The two readings lead to the following practical statement. A redistribution of the form ``\psi``
followed by a gauge step is symplectic for ``\omega_N``, and between two redistributions the
dynamics is symplectic for ``\omega`` with the weights of that interval. As soon as the new
weights, or the parameters of ``\psi``, depend on the state, the composition "flow,
redistribution, flow" is not a canonical map of the initial data. This is the same situation as an
adaptive time step that depends on the state. What a symplectic redistribution does deliver is a
map that does not coarse-grain: it keeps ``(x, p)`` exactly (the gauge step) or moves them
canonically (``\psi``), and it introduces no numerical diffusion. The
[composition defect](@ref sliced-composition-defect) of the sliced redistribution measures the
effect for one later flow step.

### [Frozen and closed-loop parameters](@id closed-loop-identity)

Let ``R_\theta`` be a family of symplectic maps of ``\mathcal{Z}`` with a parameter vector
``\theta``. A solver that determines ``\theta = \Theta(z)`` from the ensemble produces the map
``\Phi(z) = R_{\Theta(z)}(z)``, with the Jacobian

```math
D\Phi = D_z R_\theta + \partial_\theta R_\theta \, D\Theta .
```

The second term destroys the symplecticity of ``\Phi`` in general. Two maps must therefore be
distinguished: the *open-loop* map ``R_\theta`` with ``\theta`` frozen, which is symplectic by
construction, and the *closed-loop* map ``\Phi``, in which a perturbation of the incoming ensemble
also perturbs the solved parameters, as the multiplier variations do in projected variational
integrators [Kraus:2017](@cite). For maps that are one step of a parametrised Hamiltonian, the
defect has an exact form.

!!! info "Theorem (closed-loop identity)"
    Let ``H(x, p; \theta)`` be ``C^2`` in ``(x, p, \theta)``, and let
    ``\Phi(x, p) = (\bar{x}, \bar{p})`` be defined through a ``C^1`` parameter map
    ``\theta = \Theta(x, p)`` by either the type-2 symplectic Euler step with
    ``z_{\mathrm{stage}} = (x, \bar{p})`` or the implicit midpoint step with
    ``z_{\mathrm{stage}} = \tfrac12 (x + \bar{x}, p + \bar{p})``, with step ``\tau``. Then on the
    domain of ``\Phi``
    ```math
    \Phi^* \omega - \omega
    = -\tau \sum_{k=1}^{N_\theta} \mathrm{d}\Big( \frac{\partial H}{\partial \theta_k}
    (z_{\mathrm{stage}}; \theta) \Big)\Big|_{\theta = \Theta(x, p)} \wedge \mathrm{d}\Theta_k(x, p) .
    ```
    In matrix form, with ``g_k(z) := \tfrac{\partial H}{\partial \theta_k}(z_{\mathrm{stage}}(z);
    \Theta(z))``,
    ```math
    (D\Phi)^{\mathsf{T}} \mathbb{J} (D\Phi) - \mathbb{J}
    = -\tau \Big( (Dg)^{\mathsf{T}} (D\Theta) - (D\Theta)^{\mathsf{T}} (Dg) \Big) .
    ```

!!! details "Proof"
    *Symplectic Euler.* Let ``S(x, \bar{p}; \theta) := \sum_a x_a \cdot \bar{p}_a
    + \tau H(x, \bar{p}; \theta)``. By the symplectic Euler equations, the total exterior
    derivative of ``S(x, \bar{p}; \Theta(x, p))`` is
    ```math
    \begin{aligned}
    \mathrm{d} S &= \sum_a \big( \bar{p}_a + \tau \nabla_{x_a} H(x, \bar{p}; \Theta) \big) \cdot
    \mathrm{d}x_a + \sum_a \big( x_a + \tau \nabla_{\bar{p}_a} H(x, \bar{p}; \Theta) \big) \cdot
    \mathrm{d}\bar{p}_a + \tau \sum_k \frac{\partial H}{\partial \theta_k}(x, \bar{p}; \Theta) \,
    \mathrm{d}\Theta_k \\
    &= \sum_a p_a \cdot \mathrm{d}x_a + \sum_a \bar{x}_a \cdot \mathrm{d}\bar{p}_a
    + \tau \sum_k g_k \, \mathrm{d}\Theta_k .
    \end{aligned}
    ```
    Applying ``\mathrm{d}`` and ``\mathrm{d}^2 S = 0`` gives
    ``0 = \sum_a \mathrm{d}p_a \wedge \mathrm{d}x_a + \sum_a \mathrm{d}\bar{x}_a \wedge
    \mathrm{d}\bar{p}_a + \tau \sum_k \mathrm{d}g_k \wedge \mathrm{d}\Theta_k``, which rearranges
    to the identity.

    *Implicit midpoint.* With ``x_{1/2} = \tfrac12 (x + \bar{x})`` and
    ``p_{1/2} = \tfrac12 (p + \bar{p})``, expand the algebraic identity
    ```math
    \mathrm{d}\bar{x}_a \wedge \mathrm{d}\bar{p}_a - \mathrm{d}x_a \wedge \mathrm{d}p_a
    = \mathrm{d}x_{1/2,a} \wedge \mathrm{d}(\bar{p}_a - p_a)
    + \mathrm{d}(\bar{x}_a - x_a) \wedge \mathrm{d}p_{1/2,a} .
    ```
    The exterior derivative of ``H(x_{1/2}, p_{1/2}; \Theta(x, p))``, with the midpoint
    equations substituted, is
    ```math
    \mathrm{d} H = -\frac{1}{\tau} \sum_a (\bar{p}_a - p_a) \cdot \mathrm{d}x_{1/2,a}
    + \frac{1}{\tau} \sum_a (\bar{x}_a - x_a) \cdot \mathrm{d}p_{1/2,a}
    + \sum_k g_k \, \mathrm{d}\Theta_k .
    ```
    Applying ``\mathrm{d}`` (``\mathrm{d}^2 H = 0``), multiplying by ``\tau``, and using
    ``-\mathrm{d}(\bar{p}_a - p_a) \wedge \mathrm{d}x_{1/2,a} = \mathrm{d}x_{1/2,a} \wedge
    \mathrm{d}(\bar{p}_a - p_a)`` together with the algebraic identity gives the theorem. Its
    coordinate form under ``u^{\mathsf{T}} \mathbb{J} w = (\mathrm{d}x \wedge \mathrm{d}p)(u, w)``
    is the matrix identity.

### [Fixed grids and the variational closure](@id variational-closure)

!!! info "Corollary (fixed-grid no-go and variational closure)"
    Under the hypotheses of the theorem:

    1. *Fixed-grid no-go.* Every closed-loop rule ``\Phi`` that resets the positions onto a
       state-independent grid, ``\bar{x}_a = x_a^{\mathrm{grid}}``, has
       ``\mathrm{d}\bar{x}_a = 0`` for all ``a``, hence ``\Phi^* \omega \equiv 0 \ne \omega``, also
       when ``\Phi(z) = R_{\Theta(z)}(z)`` is realised at each ``z`` by an open-loop symplectic
       step.
    2. *Variational closure.* Let ``\theta = \Theta(x, p)`` be determined not by matching
       external targets but by the stationarity condition
       ```math
       \frac{\partial H}{\partial \theta_k}(z_{\mathrm{stage}}; \theta)
       = \frac{\partial \mathcal{V}}{\partial \theta_k}(\theta) , \qquad k = 1, \dots, N_\theta ,
       ```
       for a ``C^2`` potential ``\mathcal{V}`` of ``\theta`` alone. Then ``\Phi^* \omega = \omega``
       holds in the closed-loop sense (``\mathrm{d}\Theta \ne 0``).

!!! details "Proof"
    (i) is immediate from ``\Phi^* \omega = \sum_a \mathrm{d}\bar{x}_a \wedge \mathrm{d}\bar{p}_a``.
    For (ii), inserting ``g_k = \partial_{\theta_k} \mathcal{V}(\Theta)`` into the identity gives
    ```math
    \sum_k \mathrm{d}g_k \wedge \mathrm{d}\Theta_k
    = \sum_{k,l} \frac{\partial^2 \mathcal{V}}{\partial \theta_l \partial \theta_k}(\Theta) \,
    \mathrm{d}\Theta_l \wedge \mathrm{d}\Theta_k = 0
    ```
    by the symmetry of ``\nabla_\theta^2 \mathcal{V}`` and the skew-symmetry of the wedge product.

The same holds for a type-2 generating function ``S(x, \bar{p}, \theta)`` with ``\theta`` fixed
by ``\partial_\theta S = 0``: with ``\bar{S}(x, \bar{p}) = S(x, \bar{p}, \theta(x, \bar{p}))``, the
stationarity gives ``\partial_x \bar{S} = \partial_x S`` and
``\partial_{\bar{p}} \bar{S} = \partial_{\bar{p}} S``, so ``\bar{S}`` generates the same map. A
stationarity condition is a property of the generating function, however; it cannot express a
fit of the image points to targets.

The constructions of the manual therefore use parameter-wise symplecticity: for every frozen
value of the stretches, the parameters, the slices or the multipliers, the map is exactly
symplectic, and these values are computed from the markers. The gauge rezoning is the exception:
its stretches may depend on the state in any way, because the gauge step is symplectic for every
``\lambda``. The [closed loops](@ref rd-closed-loop) of the spline-projection redistribution
evaluate both sides of the identity
([`closed_loop_defect`](@ref ParticleRemapping.Redistribution.closed_loop_defect)) for a
target-matching closure and a variational one. For the kick–drift map of the Hamiltonian particle
projection with two random stages and the amplitude ``\theta(z) = 1 + \tfrac12 \sum_a \sin x_a / N``,
the symplecticity defect is ``0.17`` (``d = 1``) and ``0.16`` (``d = 2``), against
``8.6 \cdot 10^{-15}`` or less with ``\theta`` frozen at ``\theta(z_0)``
(`test/projection/stages.jl`).
